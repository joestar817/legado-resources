# Noto Sans 字体示例

字体文件保持上游字节不变，仅文件名简化为 NotoSans.ttf。上游为 [google/fonts](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notosans)，固定提交 `8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5`。

作者为 The Noto Project Authors，许可见同目录 OFL.txt。该字体主要覆盖拉丁、希腊和西里尔文字，不作为完整中文阅读字体推荐。

已通过 fontTools 加载和字符映射检查；NG 实机导入未验收。
