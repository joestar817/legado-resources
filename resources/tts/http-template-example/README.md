# HTTP TTS 接口模板

这是一个默认禁用的 NG 脚本模板，用于展示目录、导入元数据和 `options / voices / synthesize` 接口。它没有绑定任何现成服务，也不包含账号凭据。

自行配置的服务需要接收 JSON POST：`{"text":"待朗读内容","voice":"default"}`，并直接返回 MP3 音频。不同厂商的实际协议通常需要继续适配，不能将此模板视为已可用的在线 TTS 服务。

已检查脚本语法和本地请求构造；未执行外部合成或 NG 实机导入。此目录为新建示例，不包含本机原有的 20 个服务脚本。

示例脚本以 CC0-1.0 提供，可用于编写自己的适配器。
